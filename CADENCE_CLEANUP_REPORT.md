## 🔧 **Созданная чистая конфигурация**

### **Файл: `cadence-mock-clean.yaml`**
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: cadence-mock
  namespace: cloudbridge
  labels:
    app: cadence-mock
spec:
  template:
    metadata:
      labels:
        app: cadence-mock
        app.kubernetes.io/name: cadence  # ← Важно для сервиса
    spec:
      containers:
      - name: cadence-mock
        image: nginx:alpine
        ports:
        - containerPort: 7933  # gRPC
        - containerPort: 7934   # TChannel
        - containerPort: 8000  # HTTP
        # ... простая конфигурация без проблем
```

### **Ключевые особенности:**
- **Простая конфигурация** без сложных зависимостей
- **Правильные лейблы** для сервиса Cadence
- **Минимальные ресурсы** (128Mi RAM, 100m CPU)
- **Health checks** для мониторинга
- **Python HTTP сервер** для имитации Cadence API
