# Changelog

Все значимые изменения в проекте CloudBridge Relay будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Исправлено
- **Конфигурация:** Исправлен парсинг `time.Duration` из JSON строк
  - Добавлен промежуточный парсер `configRaw` с функцией `parseDuration()`
  - Теперь поддерживаются строковые значения: "30s", "5m", "1h"
- **Логгер:** Исправлено несоответствие API логгера в main.go
  - Обновлен код для использования правильного API zap логгера
  - Структурированное логирование теперь работает корректно
- **Docker:** Исправлена команда запуска в Docker контейнере
  - Правильная команда: `./relay --config config/config.json`
  - Контейнеры теперь запускаются без ошибок

### Добавлено
- **Документация:** Обновлены все основные документы
  - `docs/deployment_guide.md` - добавлен раздел о формате конфигурации
  - `docs/metrics.md` - обновлены метрики и примеры запросов
  - `docs/debugging.md` - добавлены частые проблемы и решения
  - `README.md` - обновлен с учетом исправлений
  - `docs/tech_task_monitoring_security.md` - добавлен статус выполнения

### Изменено
- **Конфигурация:** Все поля `time.Duration` теперь должны быть строками
- **Docker:** Изменена команда запуска контейнера
- **Документация:** Обновлены примеры и инструкции

## Примечания к версиям

### Semantic Versioning
- **MAJOR** - несовместимые изменения API
- **MINOR** - новая функциональность с обратной совместимостью  
- **PATCH** - исправления ошибок с обратной совместимостью

### Типы изменений
- **Добавлено** - новая функциональность
- **Изменено** - изменения в существующей функциональности
- **Устарело** - функциональность, которая будет удалена
- **Удалено** - удаленная функциональность
- **Исправлено** - исправления ошибок
- **Безопасность** - исправления уязвимостей
