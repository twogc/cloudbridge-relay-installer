### **🔥 СРОЧНЫЕ ДЕЙСТВИЯ (освободят ~50GB):**

#### **1. Очистка Docker (освободит ~46GB)**
```bash
# Удалить неиспользуемые образы
sudo docker image prune -a -f

# Удалить неиспользуемые контейнеры
sudo docker container prune -f

# Удалить неиспользуемые сети
sudo docker network prune -f

# Полная очистка (осторожно!)
sudo docker system prune -a -f --volumes
```

#### **2. Удаление старого бэкапа (освободит 1.6GB)**
```bash
# Удалить старый бэкап
rm /home/ubuntu/cloudbridge-relay-backup-20250916-221137.tar.gz
```

### **📋 ДОПОЛНИТЕЛЬНЫЕ ДЕЙСТВИЯ:**

#### **3. Очистка логов**
```bash
# Очистить старые логи
sudo journalctl --vacuum-time=7d
sudo find /var/log -name "*.log" -type f -mtime +7 -delete
```

#### **4. Очистка кэша**
```bash
# Очистить кэш пакетов
sudo apt clean
sudo apt autoremove -y
```
