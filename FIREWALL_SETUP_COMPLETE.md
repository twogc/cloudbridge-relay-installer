## 📋 Управление файрволом

### Команды управления
```bash
# Статус файрвола
sudo ufw status verbose

# Добавить правило
sudo ufw allow 8080/tcp comment "New service"

# Удалить правило
sudo ufw delete 1

# Отключить файрвол (не рекомендуется)
sudo ufw disable

# Включить файрвол
sudo ufw enable
```

### Использование скрипта
```bash
# Проверка статуса
sudo ./scripts/setup_firewall.sh --status

# Отключение (если нужно)
sudo ./scripts/setup_firewall.sh --disable

# Сброс правил
sudo ./scripts/setup_firewall.sh --reset
```
