# Руководство по безопасному добавлению сетевых карт

## Когда можно безопасно добавить сетевую карту

### ✅ Безопасные моменты для добавления:

1. **В рабочее время с мониторингом**
   - Когда вы физически находитесь рядом с сервером
   - Есть доступ к консоли VK Cloud
   - Можете быстро откатить изменения

2. **При низкой нагрузке**
   - Минимальное количество активных соединений
   - Нет критических процессов
   - Время: ночь или выходные

3. **С подготовленным планом отката**
   - Резервные копии конфигураций
   - Доступ к консоли VK Cloud
   - План восстановления SSH

### ❌ НЕ добавляйте сетевые карты когда:

1. **Высокая нагрузка на систему**
   - Активные пользователи
   - Критические процессы
   - Высокий трафик

2. **Без доступа к консоли**
   - Только SSH доступ
   - Нет физического доступа
   - Нет резервного канала связи

3. **В критическое время**
   - Рабочие часы
   - Важные дедлайны
   - Плановые работы

## Пошаговый план безопасного добавления

### Этап 1: Подготовка (5-10 минут)

```bash
# 1. Создаем резервные копии
sudo cp /etc/netplan/50-cloud-init.yaml /etc/netplan/50-cloud-init.yaml.backup
sudo cp /etc/network/interfaces /etc/network/interfaces.backup 2>/dev/null || true

# 2. Проверяем текущее состояние
ip addr show
ip route show
systemctl status networking

# 3. Записываем важную информацию
echo "Основной интерфейс: $(ip route | grep default | awk '{print $5}')" > network-info.txt
echo "Основной IP: $(hostname -I | awk '{print $1}')" >> network-info.txt
```

### Этап 2: Добавление карты в VK Cloud (2-3 минуты)

1. Зайдите в панель VK Cloud
2. Перейдите в раздел "Виртуальные машины"
3. Выберите вашу VM
4. Нажмите "Добавить сетевой интерфейс"
5. Выберите сеть (обычно ту же, что и основная карта)
6. Нажмите "Применить"

### Этап 3: Настройка в системе (5-10 минут)

```bash
# Запускаем безопасный скрипт
./network-setup-safe.sh
```

### Этап 4: Проверка (2-3 минуты)

```bash
# Проверяем SSH доступ
ssh user@your-server-ip

# Проверяем интернет
ping -c 3 8.8.8.8

# Проверяем новые интерфейсы
ip addr show
```

## План отката (если что-то пошло не так)

### Если потеряли SSH доступ:

1. **Через консоль VK Cloud:**
   ```bash
   # Восстанавливаем резервную конфигурацию
   sudo cp /etc/netplan/50-cloud-init.yaml.backup /etc/netplan/50-cloud-init.yaml
   sudo netplan apply
   ```

2. **Удаляем дополнительную карту:**
   - В панели VK Cloud
   - Удалить сетевой интерфейс
   - Перезагрузить VM

3. **Проверяем восстановление:**
   ```bash
   systemctl restart networking
   ip addr show
   ```

## Рекомендуемое время для добавления

### 🕐 Лучшее время:
- **Ночь (02:00-06:00)** - минимальная активность
- **Выходные** - больше времени на исправление
- **Праздничные дни** - низкая нагрузка

### 📅 План действий:

1. **За день до добавления:**
   - Уведомить пользователей о возможных кратковременных перерывах
   - Подготовить резервные копии
   - Протестировать план отката

2. **В день добавления:**
   - Проверить доступность консоли VK Cloud
   - Убедиться в наличии резервных копий
   - Запустить мониторинг системы

3. **После добавления:**
   - Проверить все сервисы
   - Протестировать балансировку нагрузки
   - Обновить документацию

## Мониторинг после добавления

```bash
# Создаем скрипт мониторинга
cat > monitor-network.sh << 'EOF'
#!/bin/bash
echo "=== Мониторинг сетевых интерфейсов ==="
echo "Время: $(date)"
echo ""

echo "Интерфейсы:"
ip addr show | grep -E "(ens|eth|enp)"

echo ""
echo "Маршрутизация:"
ip route show

echo ""
echo "Статистика трафика:"
cat /proc/net/dev | grep -E "(ens|eth|enp)"

echo ""
echo "Проверка доступности:"
ping -c 1 8.8.8.8 > /dev/null && echo "✅ Интернет доступен" || echo "❌ Проблемы с интернетом"
EOF

chmod +x monitor-network.sh
```

## Готовы к добавлению?

**Перед добавлением убедитесь:**

- [ ] Есть доступ к консоли VK Cloud
- [ ] Созданы резервные копии конфигураций
- [ ] Низкая нагрузка на систему
- [ ] Есть время на исправление проблем
- [ ] Протестирован план отката

**Когда все готово, запустите:**
```bash
./network-setup-safe.sh
```

---

**⚠️ Важно:** Всегда имейте план отката и доступ к консоли VK Cloud перед добавлением сетевых карт!
