## Ключевые компоненты

### 1. QUICRelayHandler
- Обрабатывает входящие QUIC соединения
- Управляет QUIC streams
- Пересылает пакеты между пирами
- Поддерживает мультитунельность

### 2. RelayManager
- Управляет P2P соединениями
- Реализует маршрутизацию пакетов
- Обеспечивает изоляцию между tenant
- Выделяет IP адреса для пиров

### 3. HeartbeatManager
- Отслеживает активность пиров
- Автоматически очищает неактивные соединения
- Поддерживает 30-секундный интервал

### 4. P2PAPIServer
- Предоставляет HTTP API для P2P операций
- Валидирует JWT токены
- Обеспечивает tenant isolation
- Управляет регистрацией пиров
