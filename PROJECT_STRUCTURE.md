## 📋 **ПРАВИЛА ОРГАНИЗАЦИИ**

### ✅ **Что НЕ перемещается:**
- Основные файлы проекта (README.md, go.mod, Makefile)
- Исходный код (cmd/, internal/, pkg/)
- Конфигурации сборки (.gitignore, .dockerignore)
- Директории развертывания (k8s/, deploy/, terraform/)

### ✅ **Что перемещается:**
- Документация → `docs/`
- Скрипты → `scripts/`
- Docker файлы → `docker/`
- Конфигурации → `configs/`
- Тесты → `tests/`
- Утилиты → `tools/`

## 🎯 **ПРЕИМУЩЕСТВА НОВОЙ СТРУКТУРЫ**

### 📁 **Организация:**
