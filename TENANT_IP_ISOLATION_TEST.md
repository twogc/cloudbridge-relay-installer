## 📊 **Анализ проблемы**

### **🔍 Обнаруженные проблемы:**

#### **1. Все тенанты используют одну подсеть**

- **Tenant C** может получить IP: `10.100.77.12`

- Нет сетевого разделения
- Возможны атаки между тенантами

## 🔧 **Правильная реализация IPAM**

### **Должно быть:**

```go
// Правильная реализация с изоляцией
func (pm *PeerManager) allocateIPForTenant(tenantID, peerID string) (string, error) {
    // 1. Получить уникальную подсеть для тенанта
    tenantSubnet := pm.getTenantSubnet(tenantID)
    
    // 2. Выделить IP в рамках подсети тенанта
    return pm.allocateIPInSubnet(tenantSubnet, peerID)
}

func (pm *PeerManager) getTenantSubnet(tenantID string) string {
    // Детерминированное выделение подсетей
    // tenant-1 -> 10.100.1.0/24
    // tenant-2 -> 10.100.2.0/24
    // tenant-3 -> 10.100.3.0/24
    
    hash := hashTenantID(tenantID)
    subnetID := hash % 65536  // 0-65535
    
    x := subnetID / 256
    y := subnetID % 256
    
    return fmt.Sprintf("10.%d.%d.0/24", x, y)
}
```
