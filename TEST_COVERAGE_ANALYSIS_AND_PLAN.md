## 🛠️ Технические требования

### Инструменты тестирования
- **Go testing framework** - основной фреймворк
- **testify/assert** - assertions
- **testify/mock** - моки
- **httptest** - HTTP тестирование
- **gomock** - генерация моков

### Структура тестов
```go
func TestFunctionName(t *testing.T) {
    // Arrange
    // Act  
    // Assert
}
```

### Mock'и и зависимости
- Создать интерфейсы для внешних зависимостей
- Использовать dependency injection
- Создать mock'и для Keycloak, Django, WireGuard

### CI/CD интеграция
- Автоматический запуск тестов при PR
- Проверка покрытия в CI
- Генерация отчетов о покрытии
