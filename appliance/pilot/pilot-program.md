# CloudBridge Appliance Pilot Program

## 🎯 Цель программы

Пилотная программа предназначена для демонстрации возможностей CloudBridge Appliance потенциальным enterprise клиентам в течение 3-6 месяцев с возможностью перехода на полную коммерческую лицензию.

## 📋 Условия пилотной программы

### **Стоимость**
- **Пилотная лицензия**: 50% от полной стоимости коробки
- **Поддержка**: Включена в стоимость пилота
- **Обучение**: 2 дня бесплатного обучения персонала
- **Интеграция**: Базовая интеграция включена

### **Длительность**
- **Минимальный период**: 3 месяца
- **Максимальный период**: 6 месяцев
- **Продление**: Возможно по согласованию

### **Ограничения пилота**
- **Пользователи**: До 50 пользователей
- **Серверы**: До 3 серверов
- **Группы**: До 3 групп
- **Пропускная способность**: До 1 Gbps
- **Функции**: Базовый набор функций
