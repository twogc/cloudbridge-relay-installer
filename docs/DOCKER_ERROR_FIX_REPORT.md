## 🚨 **Исходная проблема:**

```
Value of type "string" is not suitable for value type "Numeric (unsigned)". 
Value "WARNING: Error loading config file: open /root/.docker/config.json: permission denied\n2"
```

### **Причина:**
Docker команды в скрипте сбора метрик возвращали предупреждения вместе с числовыми данными, что приводило к ошибкам типов в Zabbix.

---

## 🛠️ **Выполненные исправления:**

### **1. Исправление Docker команд в скрипте:**
**До исправления:**
```bash
docker ps --format "{{.Names}}" 2>/dev/null | wc -l
```

**После исправления:**
```bash
docker ps --format "{{.Names}}" 2>/dev/null | grep -v "WARNING" | wc -l
```

### **2. Удаление дублирующихся UserParameter'ов:**
- Удалены дублирующиеся записи в `/etc/zabbix/zabbix_agentd.conf`
- Оставлены только рабочие UserParameter'ы

### **3. Добавление недостающих UserParameter'ов:**
- `cloudbridge.relay.connections.total` - общее количество соединений Relay
