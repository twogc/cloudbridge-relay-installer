# 🚀 Быстрый старт - VK Cloud API Manager

## Шаг 1: Настройка переменных окружения

Отредактируйте файл `setup-env.sh` с вашими данными:

```bash
# Ваши данные уже настроены в setup-env.sh:
# - Project ID: 8530029fa7b64199b2ad87c18d4620df
# - Username: info@2gc.ru
# - Region: RegionOne
```

## Шаг 2: Запуск основного скрипта

```bash
./vk-cloud-manager.sh
```

## Шаг 3: Получение токена

В меню выберите **"1. Получить токен"** и введите пароль от вашей учетной записи.

## Шаг 4: Просмотр доступных ресурсов

1. **Показать сети**: выберите "2. Показать сети"
2. **Показать подсети**: выберите "3. Показать подсети"
3. **Показать порты**: выберите "4. Показать порты"

## Шаг 5: Создание Anycast IP

1. Выберите **"12. Создать Anycast IP"**
2. Введите название: `cloudbridge-relay-anycast`
3. Введите описание: `Anycast IP для CloudBridge Relay`

## Шаг 6: Создание балансировщика

1. Выберите **"7. Создать балансировщик"**
2. Введите название: `cloudbridge-lb`
3. Введите ID подсети (из шага 4)
4. Введите зону доступности: `GZ1`

## Шаг 7: Привязка IP к Anycast

1. Выберите **"13. Привязать IP к Anycast"**
2. Введите ID Anycast IP (из шага 5)
3. Введите ID порта (из списка портов)

## 🎯 Автоматическая настройка

Для полной автоматической настройки выберите **"15. Настроить CloudBridge Relay (полная настройка)"**

## 📋 Полезные команды

```bash
# Проверка статуса балансировщиков
./vk-cloud-manager.sh
# Выберите "6. Показать балансировщики"

# Проверка статуса Anycast IP
./vk-cloud-manager.sh
# Выберите "11. Показать Anycast IP"

# Добавление healthcheck
./vk-cloud-manager.sh
# Выберите "14. Добавить healthcheck для Anycast"
```

## 🔧 Отдельные скрипты

```bash
# Только балансировщик
./loadbalancer-api.sh

# Только Anycast IP
./anycast-api.sh
```

## ⚠️ Важные замечания

1. **Healthcheck**: Обязательно настройте healthcheck для Anycast IP
2. **Security Groups**: Разрешите трафик с `169.254.169.100/32` для healthcheck
3. **Зоны доступности**: Используйте одну зону для оптимальной производительности

## 🆘 Если что-то не работает

1. Проверьте, что токен получен успешно
2. Убедитесь, что доступ по API активирован в личном кабинете
3. Проверьте правильность ID подсетей и портов
4. Убедитесь, что используется SDN Sprut для Anycast IP
