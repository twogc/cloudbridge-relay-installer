# 📄 Использование опыта SoftEther VPN в проекте CloudBridge Relay

## Введение

Проект **SoftEther VPN** — это зрелое и широко используемое VPN-решение с мультипротокольной поддержкой, API-интерфейсами и расширенными механизмами обхода ограничений. Несмотря на различия архитектуры, в **CloudBridge Relay** можно использовать множество концепций, подходов и решений из SoftEther для усиления безопасности, гибкости и управляемости.

---

## 🔐 1. Аутентификация и безопасность

### ✅ Что можно использовать:

| Элемент                | Применение в CloudBridge Relay                         | Комментарий                      |
| ---------------------- | ------------------------------------------------------ | -------------------------------- |
| **TLS-аутентификация** | Аутентификация агентов через TLS + client certs (опц.) | Альтернатива JWT                 |
| **X.509 сертификаты**  | Проверка подписи агента через CA                       | Повышает безопасность            |
| **JWT Access Control** | Используется аналогично для короткоживущих токенов     | Уже реализовано, можно расширить |

### 🔧 Рекомендации:

* Использовать TLS 1.3 с обязательной проверкой fingerprint или client cert (mTLS).
* Добавить политики доступа по токену: разрешённые порты, лимит IP.

## 🔌 2. Объединение серверов в виртуальную сеть

### Что хотят клиенты:

* Создать единую виртуальную сеть, в которой серверы в разных офисах видят друг друга по IP
* Всё соединение защищёно TLS, без VPN и сложной настройки
* Управлять сетью через личный кабинет

### Реализация в CloudBridge Relay

* Каждый клиент получает IP (напр., 10.12.0.X)
* Relay-сервер маршрутизирует пакеты между клиентами
* В Django-панели: список серверов, IP, отображение карты
* Сетевая ACL: кто к кому имеет доступ

## 🔄 3. Протоколы и совместимость

### Мультипротокольная поддержка:

* **SSTP** - для Windows-клиентов
* **OpenVPN** - для кроссплатформенной поддержки
* **L2TP/IPsec** - для мобильных устройств
* **SoftEther Protocol** - для максимальной производительности

### Преимущества:

* Гибкость выбора протокола под конкретные нужды
* Обход блокировок через разные протоколы
* Поддержка различных клиентских устройств
