# 🚀 Ультра-минимальная установка Grafana в VK Cloud

## 📋 Что это такое

Это **самая простая возможная конфигурация** для установки только Grafana в VK Cloud Kubernetes. Никаких дополнительных компонентов - только Grafana.

## 🎯 Цель

Если стандартная установка Prometheus Stack не работает, эта конфигурация должна сработать, так как использует минимальные ресурсы.

## 📝 Шаги установки

### 1. Откройте консоль VK Cloud
- https://mcs.mail.ru/
- Войдите в аккаунт
- Выберите проект с кластером `kubernetes-cluster-8926`

### 2. Перейдите к кластеру
- Меню слева → **Kubernetes**
- Найдите `kubernetes-cluster-8926`
- Нажмите на него

### 3. Добавьте аддон
- Вкладка **Аддоны**
- **Добавить аддон**
- Выберите **kube-prometheus-stack**

### 4. Заполните поля
- **Название приложения**: `grafana-only`
- **Пространство имен**: `grafana-monitoring`
- **Пароль Grafana**: `admin123`

### 5. Вставьте конфигурацию
Скопируйте **ВСЕ** содержимое файла `configs/kube-prometheus-stack-ultra-minimal.yaml` в поле **Код настройки аддона**

### 6. Установите
- **Установить аддон**
- Ждите 5-10 минут

## 🔍 Проверка

### В консоли VK Cloud:
1. **Ресурсы кластера** → **Поды**
2. Найдите namespace `grafana-monitoring`
3. Должен быть один под `grafana-only-grafana-xxx`

### Статус пода должен быть **Running**

## 🌐 Доступ к Grafana

### Способ 1: Port-forward
```bash
kubectl -n grafana-monitoring port-forward service/grafana-only-grafana 3000:80
```

### Способ 2: Через консоль VK Cloud
1. Найдите сервис `grafana-only-grafana`
2. Нажмите на него
3. Используйте **Внешний IP** или **Внутренний IP**

## 🔑 Логин в Grafana
- **URL**: http://localhost:3000 (при port-forward)
- **Логин**: `admin`
- **Пароль**: `admin123`

## ⚠️ Важные замечания

### ✅ Что будет установлено:
- Только Grafana
- Минимальные ресурсы (10m CPU, 16Mi RAM)
- Без persistent storage

### ❌ Что НЕ будет установлено:
- Prometheus
- Alertmanager
- Prometheus Operator
- Node Exporter
- Kube State Metrics

## 🚨 Если не работает

### Проблема: "Не удалось установить аддон"
1. **Проверьте ресурсы** - должно быть минимум 1 CPU и 2GB RAM свободно
2. **Попробуйте еще раз** - иногда нужно несколько попыток
3. **Используйте локальную установку** как альтернативу

### Альтернатива - локальная установка:
```bash
# Остановите локальные контейнеры
docker stop cloudbridge-grafana cloudbridge-prometheus

# Запустите только Grafana
docker run -d --name grafana-local -p 3000:3000 \
  -e GF_SECURITY_ADMIN_PASSWORD=admin123 \
  grafana/grafana:10.1.5
```

## 📊 Следующие шаги

После успешной установки Grafana:
1. **Добавьте Prometheus** как источник данных
2. **Настройте дашборды** для CloudBridge
3. **Добавьте алерты** для критических событий
