## 1. Обзор продукта и рынка

### 1.1 Описание продуктовых линеек

#### **Enterprise-коробка (для крупного бизнеса)**
- **Целевая аудитория:** Корпорации 1000+ сотрудников
- **Модель развертывания:** On-premise в собственной инфраструктуре
- **Ключевые особенности:**
  - Полная изоляция инфраструктуры
  - Выделенные серверы и сетевая инфраструктура
  - Эксклюзивный доступ ко всем возможностям
  - Полный контроль над данными и безопасностью
  - Кастомные интеграции и API доступ
  - White-label лицензирование

#### **Облачное решение на VK Cloud (для SMB)**
- **Целевая аудитория:** Малый и средний бизнес (10-1000 сотрудников)
- **Модель развертывания:** SaaS на российской платформе VK Cloud
- **Ключевые особенности:**
  - Соответствие 152-ФЗ и 187-ФЗ
  - Высокая безопасность и производительность
  - Автоматическое масштабирование
  - Простота развертывания и управления
  - Поддержка стартапов и SMB

### 1.2 Анализ рынка

#### **Российский рынок информационной безопасности**

**TAM (Total Addressable Market) - Рынок ИБ в РФ:**
- **Общий рынок ИБ в РФ**: ~₽250 млрд (2026), ~₽320 млрд (2027)
- **Рост рынка**: ~30% г/г
- **Основные сегменты**: сетевые средства защиты, endpoint protection, SIEM, IAM

**SAM (Serviceable Addressable Market) - Рынок secure access/NGFW в РФ:**
- **Рынок NGFW/VPN/ZTNA в РФ**: ~₽35-45 млрд (2026), ~₽45-60 млрд (2027)
- **Доля secure access**: ~25-30% от общего рынка ИБ
- **Ключевые драйверы**: импортозамещение, цифровизация, регуляторные требования

**SOM (Serviceable Obtainable Market) - Целевая доля CloudBridge Relay:**
- **Цель к 2027**: 2-3% от SAM
- **Абсолютное значение**: ~₽0,7-1,5 млрд ARR
- **Основание**: уникальные технологии + российская локализация + сертификации

#### **Источники данных:**
- **ICT Moscow**: Анализ рынка ИБ РФ 2026
- **Российский Конгресс по информационной безопасности**: Отчеты по сегментам 2026-2027
- **Минцифры РФ**: Статистика по импортозамещению 2026-2027
- **РБК**: Анализ рынка кибербезопасности РФ 2023-2024
- **e-kontur.ru**: Налоговые льготы для ПО из реестра
- **infotecs.ru**: Официальный прайс-лист ViPNet
- **yandex.cloud**: Тарифы на облачные сервисы
- **vbr.ru**: Комиссии по СБП
