# 🔧 Обновление ресурсов кластера VK Cloud

## 📋 Проблема
Поддержка VK Cloud сообщила: *"есть подозрение на нехватку ресурсов, просьба увеличить флейвор для воркер ноды"*

## 🎯 Решение: Увеличить флейвор

### Текущее состояние:
- **CPU**: 3 vCPU
- **RAM**: 8 ГБ
- **Проблема**: Таймаут при установке Prometheus Stack

### Рекомендуемый флейвор:
- **CPU**: 4 vCPU
- **RAM**: 16 ГБ
- **Диск**: 50 ГБ
- **Стоимость**: ~2000₽/месяц

## 📝 Пошаговая инструкция

### 1. Откройте консоль VK Cloud
- https://mcs.mail.ru/
- Войдите в аккаунт `info@2gc.ru`

### 2. Перейдите к кластеру
- Меню слева → **Kubernetes**
- Найдите `kubernetes-cluster-6379`
- Нажмите на него

### 3. Измените конфигурацию
- Нажмите **Изменить конфигурацию** или **Редактировать**
- Найдите раздел **Node Groups**
- Нажмите **Изменить** на воркер ноде

### 4. Выберите новый флейвор
- **CPU**: 4 vCPU
- **RAM**: 16 ГБ
- **Диск**: 50 ГБ (или больше)
- Нажмите **Сохранить**

### 5. Подтвердите изменения
- Подтвердите обновление
- Дождитесь завершения (5-10 минут)
- Кластер будет перезапущен

## 🔍 Проверка обновления

### В консоли VK Cloud:
1. Перейдите к кластеру
2. Проверьте **Параметры кластера**
3. Должно быть: **4 vCPU / 16 ГБ RAM**

### Проверьте узлы:
```bash
kubectl get nodes
kubectl describe node
```

## 🚀 Установка Prometheus Stack

### После обновления ресурсов:

1. **Перейдите к аддонам**
   - Вкладка **Аддоны**
   - **Добавить аддон**
   - Выберите **kube-prometheus-stack**

2. **Заполните поля**
   - **Название**: `cloudbridge-prometheus`
   - **Namespace**: `prometheus-monitoring`
   - **Пароль**: `CloudBridge2025!`

3. **Вставьте конфигурацию**
   Используйте файл `configs/kube-prometheus-stack-optimized.yaml`

4. **Установите**
   - **Установить аддон**
   - Ждите 10-15 минут
