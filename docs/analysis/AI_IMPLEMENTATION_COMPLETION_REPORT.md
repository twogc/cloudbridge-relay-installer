## 🔧 Интеграция с CloudBridge Relay

### **API Integration:**
```bash
# Запуск AI сервиса
./ai-service --config config/ai-config.yaml

# Проверка статуса
curl http://localhost:8083/api/v1/ai/status

# Обнаружение аномалий
curl -X POST http://localhost:8083/api/v1/ai/anomaly/detect \
  -H "Content-Type: application/json" \
  -d '{"metrics": {...}}'

# Предсказание нагрузки
curl -X POST http://localhost:8083/api/v1/ai/predict/load \
  -H "Content-Type: application/json" \
  -d '{"horizon": 24}'

# Оптимизация маршрута
curl -X POST http://localhost:8083/api/v1/ai/route/optimize \
  -H "Content-Type: application/json" \
  -d '{"source": "node1", "destination": "node2"}'
```

### **Конфигурация:**
```yaml
# config/ai-config.yaml
ai:
  enabled: true
  mode: "cpu-only"
  models:
    anomaly_detection:
      enabled: true
      algorithm: "isolation_forest"
      threshold: 0.8
    load_prediction:
      enabled: true
      algorithm: "arima"
      forecast_horizon: 24
    route_optimization:
      enabled: true
      algorithm: "multi_armed_bandit"
      exploration_rate: 0.1
```
