## 🎯 Краткое резюме

Cadence Web UI был успешно развернут в Kubernetes кластере, но испытывает проблемы с gRPC подключением к Cadence сервису. Интерфейс загружается и отображается корректно, но не может получить данные о доменах из-за ошибки "Call cancelled".

### 3. **Сетевое подключение:**

## ❌ Проблемы

### 1. **gRPC подключение:**
- ❌ Ошибка "Call cancelled" при попытке получить домены
- ❌ gRPC статус код: 1 (CANCELLED)
- ❌ Подключение устанавливается, но затем прерывается

### 2. **Конфигурация:**
- ❌ Возможные проблемы с gRPC протоколом
- ❌ Cadence может не принимать внешние gRPC подключения
- ❌ Проблемы с TLS/SSL или таймаутами

## 💡 Альтернативное решение

### **Grafana Dashboard для мониторинга Cadence:**

**✅ Рабочее решение:** Используйте Grafana дашборды для мониторинга Cadence

#### **Доступ:**
- **URL:** http://localhost:3000
- **Дашборды:** Cadence Workflow Engine, Minikube Infrastructure
- **Функции:** Метрики, алерты, визуализация

#### **Запуск:**
```bash
# Запуск всех UI интерфейсов
./scripts/monitoring-ui.sh start

# Открытие Grafana
./scripts/monitoring-ui.sh grafana
```

#### **Преимущества:**
- ✅ Стабильно работает
- ✅ Богатые возможности визуализации
- ✅ Интеграция с Prometheus
- ✅ Настраиваемые дашборды
