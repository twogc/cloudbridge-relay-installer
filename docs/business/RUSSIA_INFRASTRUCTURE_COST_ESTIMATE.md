**Дата**: 2025-10-20
**Регион**: Россия (Москва + Санкт-Петербург)
**Тип развёртывания**: Production

## Executive Summary

Полный расчёт инфраструктуры для развёртывания CloudBridge Platform в России с учётом:
- Kubernetes кластеры
- Managed сервисы (БД, кэш, мониторинг)
- Сетевая инфраструктура
- Домены и сертификаты
- Персонал и поддержка

### BGP Anycast (для DNS)

```yaml
Опция 1: Через Selectel BGP Anycast
  Стоимость: ~5,000 ₽/мес + traffic

Опция 2: Через собственный ASN
  Регистрация ASN (RIPE NCC): €2,000 (~200,000 ₽) одноразово
  IP блок /24 (256 адресов): €50/год (~5,000 ₽/год)
  Transit провайдеры (2-3 peer):
    - Tier-2 provider: 5,000-10,000 ₽/мес per peer
    - Минимум 2 peers для redundancy

  ИТОГО (через ASN): ~15,000 ₽/мес + 200,000 ₽ setup
```

**Рекомендация**: Начать с Selectel BGP Anycast (5,000 ₽/мес), переход на ASN позже.

### Оптимизация затрат:

1. **Reserved Instances**: Скидка 20-30% при предоплате на год
2. **Spot Instances**: Для non-critical workloads (скидка до 70%)
3. **Auto-scaling**: Сократить расходы в off-peak часы
4. **CDN**: Использовать Yandex CDN для снижения трафика
5. **Compression**: Сжатие данных снижает traffic costs на 50%
