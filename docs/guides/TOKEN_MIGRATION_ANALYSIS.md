## 🚀 ЛОГИКА РАБОТЫ СОЕДИНЕНИЙ

### **1. Quick Protocol Flow**
```
┌─────────────────────────────────────────────────────────────┐
│                    QUICK PROTOCOL FLOW                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─────────────┐                                           │
│  │   Клиент    │                                           │
│  └─────────────┘                                           │
│         │                                                  │
│         │ 1. POST /api/v1/quick/connect                    │
│         │    Authorization: Bearer <quick-token>           │
│         │    {                                              │
│         │      "target_server": "server-123",              │
│         │      "connection_type": "wireguard",             │
│         │      "client_config": {                          │
│         │        "endpoint": "192.168.1.100:51820",       │
│         │        "public_key": "client-public-key"         │
│         │      }                                           │
│         │    }                                             │
│         ├─────────────────────────────────────────────────►│
│         │                                                  │
│         │ 2. Валидация токена                              │
│         │    - Проверка protocol_type = "quick"           │
│         │    - Проверка scope = "quick-connect-claims"    │
│         │    - Проверка лимитов (max_connections)         │
│         │                                                  │
│         │ 3. Создание соединения                           │
│         │    - Генерация connection_id                     │
│         │    - Настройка WireGuard                         │
│         │    - Применение лимитов                          │
│         │                                                  │
│         │ 4. Ответ                                         │
│         │    {                                              │
│         │      "status": "success",                        │
│         │      "connection_id": "quick-conn-xxx",          │
│         │      "endpoint": "relay-endpoint",               │
│         │      "config": { ... }                           │
│         │    }                                             │
│         │◄─────────────────────────────────────────────────┤
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
