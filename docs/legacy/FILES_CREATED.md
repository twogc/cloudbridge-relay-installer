# Созданные файлы для развертывания CloudBridge Relay в VK Cloud

## Основные файлы проекта

### Документация
- **`README.md`** - Главный README с обзором проекта
- **`VK_CLOUD_DEPLOYMENT_GUIDE.md`** - Подробное руководство по развертыванию (200+ страниц)
- **`QUICK_DEPLOYMENT_CHECKLIST.md`** - Быстрая шпаргалка для развертывания
- **`README_DEPLOYMENT.md`** - Обзор документации
- **`DOCKER_MIRRORS_SETUP.md`** - Настройка зеркал Docker Hub для России
- **`FILES_CREATED.md`** - Этот файл со списком всех созданных файлов

### Автоматические скрипты
- **`deploy.sh`** - Полный скрипт автоматического развертывания
- **`setup-docker-mirrors.sh`** - Скрипт настройки зеркал Docker Hub

### Kubernetes манифесты (k8s-manifests/)
- **`00-namespace.yaml`** - Namespace для CloudBridge
- **`01-pvc.yaml`** - PersistentVolumeClaim для логов, Cadence и registry
- **`02-secrets.yaml`** - Секреты для аутентификации и TLS
- **`03-configmap.yaml`** - ConfigMap с конфигурацией CloudBridge
- **`04-registry.yaml`** - Docker Registry deployment и service
- **`05-deployments.yaml`** - Deployments для всех сервисов
- **`06-services.yaml`** - Services для всех компонентов
- **`07-ingress.yaml`** - Ingress для внешнего доступа
- **`08-servicemonitor.yaml`** - ServiceMonitor для Prometheus

## Быстрый старт

### 1. Клонирование и настройка
```bash
git clone <repository-url>
cd cloudbridge-relay-installer
```

### 2. Настройка зеркал Docker Hub
```bash
sudo ./setup-docker-mirrors.sh
```

### 3. Настройка окружения
```bash
source openstack_auth.sh
export KUBECONFIG=~/.kube/config-vkcloud
```

### 4. Автоматическое развертывание
```bash
./deploy.sh
```
