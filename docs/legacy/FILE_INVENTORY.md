## Определения типов

- **STATUS_REPORT**: Отчеты о текущем статусе, прогрессе, исправлениях, тестировании, развертывании
- **COMPLETION_REPORT**: Отчеты о завершении интеграции, реализации, финальные отчеты
- **ANALYSIS**: Технические анализы, обзоры архитектуры, спецификации
- **LONG_LIVED**: Справочная документация, чек-листы, запросы в поддержку, архитектурные описания
