# CloudBridge Relay - Отчет по тестированию через интернет

## Цель тестирования:
Протестировать CloudBridge Relay клиентов через интернет домены и поддомены.

## Что было протестировано:

### 1. **API доступность через NodePort:**
- *Health endpoint** - `http://192.168.58.2:30080/health` (200 OK)
- *P2P API** - `http://192.168.58.2:32500/api/v1/tenants/test/peers/register` (200 OK)
- *Регистрация пира** - успешно зарегистрирован с IP `10.100.77.10`

### 2. **Порты и сервисы:**
- *Порт 5550** - Health Check (работает)
- *Порт 5552** - P2P API (работает)
- *Порт 32500** - NodePort для P2P API (работает)
- *Порт 30080** - NodePort для Health Check (работает)

### 3. **UFW Firewall:**
- *Все порты открыты** - 5552/tcp, 5553/udp, 19302/udp, 5551/tcp, 9090/udp, 8443/tcp, 51820/udp
- *Чистая конфигурация** - удалены дублирующиеся правила
- *Правильные комментарии** - каждое правило описано

### 4. **Kubernetes сервисы:**
- *cloudbridge-relay-external** - NodePort сервис работает
- *Endpoints активны** - 3 пода подключены
- *Health checks** - все проверки проходят

## ⚠️ Проблемы с поддоменами:

### 1. **Ingress маршрутизация:**
-  **relay.2gc.ru/health** - 503 Service Unavailable
-  **relay.2gc.ru/api/** - 503 Service Unavailable
-  **edge.2gc.ru/health** - 404 Not Found

### 2. **Причины проблем:**
- **Nginx конфигурация** - не все пути настроены
- **SSL сертификаты** - проблемы с поддоменами
- **Ingress маршрутизация** - неправильная настройка путей

### 1. **Исправить Nginx конфигурацию:**
```nginx

}

location /api/ {
    proxy_pass http://192.168.58.2:32500;
}
```
