# UFW Cleanup - Наведение порядка в firewall

## Текущие проблемы:

1. **Дублирующиеся правила** - много одинаковых портов
2. **Ненужные порты** - старые тестовые порты
3. **Неправильные протоколы** - например, 8443/udp вместо 8443/tcp
4. **Отсутствие комментариев** - некоторые правила без описания

## Целевая конфигурация:

### Основные порты:
- **22/tcp** - SSH
- **80/tcp** - HTTP
- **443/tcp** - HTTPS

### CloudBridge Relay - Критические:
- **5552/tcp** - P2P API
- **5553/udp** - P2P QUIC
- **19302/udp** - STUN

### CloudBridge Relay - Рекомендуемые:
- **5551/tcp** - Health Check
- **9090/udp** - QUIC Transport
- **8443/tcp** - MASQUE HTTP/3
- **51820/udp** - WebRTC P2P

### Служебные:
- **10050** - Zabbix Agent (только с 10.0.0.241)

## План очистки:

1. **Сбросить UFW** к начальному состоянию
2. **Добавить только нужные правила** с правильными комментариями
3. **Проверить конфигурацию**
4. **Сохранить резервную копию**

## Внимание:
- SSH порт 22 должен быть открыт ВСЕГДА
- Не удалять правила для Zabbix (10.0.0.241)
- Сохранить все CloudBridge Relay порты
