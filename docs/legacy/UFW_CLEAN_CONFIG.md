## Команды для воссоздания конфигурации:

```bash
# Сброс UFW
sudo ufw --force reset

# Настройка политик по умолчанию
sudo ufw default deny incoming
sudo ufw default allow outgoing

# Основные порты
sudo ufw allow 22/tcp comment "SSH"
sudo ufw allow 80/tcp comment "HTTP"
sudo ufw allow 443/tcp comment "HTTPS"

# Служебные порты
sudo ufw allow from 10.0.0.241 to any port 10050 comment "Zabbix Agent"

# CloudBridge Relay - Критические
sudo ufw allow 5552/tcp comment "CloudBridge P2P API"
sudo ufw allow 5553/udp comment "CloudBridge P2P QUIC"
sudo ufw allow 19302/udp comment "CloudBridge STUN"

# CloudBridge Relay - Рекомендуемые
sudo ufw allow 5551/tcp comment "CloudBridge Health Check"
sudo ufw allow 9090/udp comment "CloudBridge QUIC Transport"
sudo ufw allow 8443/tcp comment "CloudBridge MASQUE HTTP/3"
sudo ufw allow 51820/udp comment "CloudBridge WebRTC P2P"

# Включение UFW
sudo ufw --force enable
```

## Статистика очистки:

### До очистки:
- **55+ правил** - много дублирующихся
- **Неправильные протоколы** - 8443/udp, 5553/tcp
- **Ненужные порты** - 5550, 5554, 5555, 8080, 8081, 18080, 18443, 8444, 30091, 30443, 30844, 32500
- **Отсутствие комментариев** - многие правила без описания

### После очистки:
- **11 правил** - только необходимые
- **Правильные протоколы** - все протоколы соответствуют назначению
- **Только нужные порты** - только CloudBridge Relay порты
- **Все с комментариями** - каждое правило описано

## Безопасность:

### Высокая безопасность:
- **5552/TCP** - P2P API (требует JWT токен)
- **8443/TCP** - MASQUE HTTP/3 (TLS 1.3)

### Средняя безопасность:
- **5553/UDP** - P2P QUIC (QUIC шифрование)
- **19302/UDP** - STUN (публичный, но ограниченный)
- **9090/UDP** - QUIC Transport (QUIC шифрование)
- **51820/UDP** - WebRTC (WebRTC шифрование)

### Низкая безопасность:
- **5551/TCP** - Health Check (публичный health check)

## Преимущества чистой конфигурации:

1. **Читаемость** - легко понять назначение каждого порта
2. **Безопасность** - только необходимые порты открыты
3. **Производительность** - меньше правил для обработки
4. **Обслуживание** - легко добавлять/удалять правила
5. **Документированность** - все правила с комментариями
