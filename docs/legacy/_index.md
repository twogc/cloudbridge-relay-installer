## Canonical Documentation

After restructuring, the active documentation structure is:

```
docs/
├── README.md                    # Human docs index
├── analysis/                    # Technical domain analyses
├── architecture/                # 5 canonical architecture docs
├── business/                    # Investor, market, executive
├── compliance/                  # Compliance docs
├── deployment/                  # Setup guides (no reports)
├── guides/                      # ~15 key deployment/setup/developer guides
├── integration/                 # PROMETHEUS_METRICS_SCHEMA.md + grafana
├── legacy/                      # This directory — archived docs
├── monitoring/                  # README.md (monitoring overview)
├── network/                     # Networking reference (ports, tokens, subdomains)
├── operations/                  # SERVICE_CATALOG.md
├── roadmap/                     # Current strategic/MVP plans
├── security/                    # Security policies and guides
└── troubleshooting/             # Runbooks
```

**Agent-oriented overview:** [openwiki/quickstart.md](../../openwiki/quickstart.md)
