# 🚀 CloudBridge запускает первый Anycast Relay в России

## Москва, 14 августа 2025 года

**CloudBridge** объявляет о запуске первого в России **Anycast Relay** сервера в зоне доступности Москва. Это знаковое событие для российской IT-инфраструктуры, которое открывает новые возможности для высоконадежного и быстрого соединения серверов.

## 🌐 Первый Anycast Relay в России

CloudBridge Relay теперь доступен по адресу **`relaymsk1.2gc.uk`** и обеспечивает:

- **Отказоустойчивость**: Anycast IP `83.166.235.45` автоматически направляет трафик на ближайший доступный сервер
- **Высокую доступность**: 99.9% uptime благодаря распределенной архитектуре
- **Низкую задержку**: Оптимизированная маршрутизация для российских пользователей
- **Масштабируемость**: Автоматическое масштабирование под нагрузку

## 🔧 Технические характеристики

### Инфраструктура
- **Зона доступности**: Москва (MS1)
- **Anycast IP**: `83.166.235.45`
- **LoadBalancer**: Автоматическое распределение нагрузки
- **Протоколы**: HTTP/HTTPS, WireGuard, QUIC

### Портовая схема
- **80**: HTTP (основной трафик)
- **443**: HTTPS (защищенное соединение)
- **8081**: API CloudBridge Relay
- **51820**: WireGuard (VPN туннели)
- **9090**: QUIC (быстрый протокол)
