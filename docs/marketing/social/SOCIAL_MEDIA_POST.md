# 🚀 CloudBridge запускает первый Anycast Relay в России!

## 📢 Анонс

**CloudBridge** объявляет о запуске первого в России **Anycast Relay** сервера в зоне доступности Москва! 🎉

## 🌐 Что это значит?

Теперь у вас есть доступ к высоконадежному и быстрому соединению серверов через **`relaymsk1.2gc.uk`**

### ✅ Что уже работает:
- Anycast IP `83.166.235.45` - автоматическая отказоустойчивость
- LoadBalancer с 99.9% uptime
- REST API для управления
- WireGuard и QUIC протоколы

### 🔄 Скоро в релизе:
- Peer-to-Peer подключение серверов
- Server-Client архитектура
- Автоматическое обнаружение узлов

## 🎯 Преимущества

- **Отказоустойчивость** - автоматическое переключение на резервные серверы
- **Низкая задержка** - оптимизированная маршрутизация в России
- **Простота интеграции** - REST API для быстрого подключения
- **Безопасность** - WireGuard шифрование по умолчанию

## 🔧 Технические детали

