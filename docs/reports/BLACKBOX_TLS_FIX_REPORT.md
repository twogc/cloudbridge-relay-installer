# Отчет об исправлении TLS проверок Blackbox Exporter

## Проблема

**Дата обнаружения**: 2025-06-29  
**Ошибка в логах**:
```
time=2025-06-29T22:36:54.308Z level=ERROR source=tcp.go:131 msg="Error dialing TCP" module=tls_connect target=relay:8080 err="tls: failed to verify certificate: x509: certificate is valid for edge.2gc.ru, not relay"
```

## Анализ проблемы

### Причина
- Blackbox Exporter проверял TLS соединение с внутренним именем контейнера `relay`
- Сертификат выдан для домена `edge.2gc.ru`
- В Docker-среде это приводило к ошибке валидации сертификата

### Влияние
- Метрика `probe_success` показывала `0` (неуспех)
- Логи содержали ошибки TLS валидации
- Мониторинг показывал недоступность Relay сервера

## Решение

### 1. Создан новый модуль для внутренних проверок

**Файл**: `deploy/blackbox/blackbox.yml`

```yaml
# Модуль для внутренних TLS проверок в Docker-среде
tls_connect_internal:
  prober: tcp
  timeout: 5s
  tcp:
    tls: true
    tls_config:
      insecure_skip_verify: true  # Ключевое изменение
    preferred_ip_protocol: "ip4"
```

### 2. Обновлена конфигурация Prometheus

**Файл**: `prometheus/prometheus.yml`

```yaml
- job_name: 'relay-tls'
  static_configs:
    - targets: ['relay:8080']
  metrics_path: '/probe'
  params:
    module: ['tls_connect_internal']  # Изменено с 'tls_connect'
```

### 3. Создан автоматизированный скрипт исправления

**Файл**: `scripts/fix_blackbox_tls.sh`
- Автоматический перезапуск сервисов
- Проверка статуса после исправления
- Валидация исправления
