### 🔧 Основной CI/CD Pipeline (`.github/workflows/ci-cd.yml`)

**Улучшения:**
- ✅ **Trivy**: Сканирование уязвимостей с фокусом на CRITICAL/HIGH

- ✅ **Кастомные скрипты**: Интеграция локальных security scripts
- ✅ **Артефакты**: Автоматическое сохранение security reports
- ✅ **SARIF**: Интеграция с GitHub Security tab

- Push в `main` и `develop`
- Pull Request в `main`
