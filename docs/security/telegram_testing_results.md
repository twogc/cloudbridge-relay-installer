## 🔧 Ключевые исправления

### **1. Обработка переносов строк:**
```bash
# Добавлено во все скрипты:
FORMATTED_MESSAGE=$(printf '%b' "$MESSAGE")
```

### **2. Правильное экранирование:**
```bash
# Только амперсанд:
message=$(echo "$message" | sed 's/&/\&amp;/g')
```

### **3. Замена HTML тегов на простой текст:**
```bash
# Было:
local message="🚨 <b>ALERT: Заголовок</b>"

# Стало:
local message="ALERT: Заголовок"
```

### **4. Удаление эмодзи:**
```bash
# Было:
message="🚨 ALERT: Обнаружены подозрительные процессы"

# Стало:
message="ALERT: Обнаружены подозрительные процессы"
```

### **5. Единообразный parse_mode:**
```bash
# Все скрипты используют:
parse_mode=HTML
```
