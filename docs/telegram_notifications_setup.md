# Настройка Telegram уведомлений для Lynis

## Обзор

Скрипт `scripts/lynis_with_telegram.sh` позволяет запускать аудит безопасности Lynis и автоматически отправлять результаты в Telegram.

## Настройка Telegram бота

### 1. Создание бота

1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например, "CloudBridge Security Bot")
   - Введите username бота (должен заканчиваться на 'bot', например "cloudbridge_security_bot")
4. Сохраните токен бота (выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Получение Chat ID

#### Вариант 1: Личный чат
1. Найдите вашего бота по username
2. Отправьте ему любое сообщение (например, "/start")
3. Откройте в браузере: `https://api.telegram.org/bot<TOKEN>/getUpdates`
4. Найдите в ответе `"chat":{"id":123456789}` - это ваш Chat ID

#### Вариант 2: Групповой чат
1. Добавьте бота в группу
2. Отправьте сообщение в группу
3. Проверьте `https://api.telegram.org/bot<TOKEN>/getUpdates`
4. Chat ID группы будет отрицательным числом

### 3. Настройка скрипта

Откройте файл `scripts/lynis_with_telegram.sh` и измените строки:

```bash
TELEGRAM_BOT_TOKEN="ваш_токен_бота"
TELEGRAM_CHAT_ID="ваш_chat_id"
```

## Использование

### Запуск аудита с уведомлениями
```bash
sudo ./scripts/lynis_with_telegram.sh
```

### Тестовая отправка
```bash
sudo ./scripts/lynis_with_telegram.sh --test
```

### Показать справку по настройке
```bash
./scripts/lynis_with_telegram.sh --setup
```

## Автоматизация

### Запуск по расписанию (cron)

Добавьте в crontab для ежедневного запуска в 2:00:
```bash
sudo crontab -e
```

Добавьте строку:
```
0 2 * * * /home/ubuntu/cloudbridge-relay-installer/scripts/lynis_with_telegram.sh
```

### Запуск после обновлений системы

Создайте скрипт для автоматического запуска после обновлений:
```bash
sudo nano /etc/apt/apt.conf.d/99-lynis-audit
```

Добавьте:
```
DPkg::Post-Invoke {"cd /home/ubuntu/cloudbridge-relay-installer && ./scripts/lynis_with_telegram.sh";};
```

## Безопасность

- Токен бота должен быть секретным
- Не публикуйте токен в публичных репозиториях
- Используйте переменные окружения для продакшена:
  ```bash
  export TELEGRAM_BOT_TOKEN="ваш_токен"
  export TELEGRAM_CHAT_ID="ваш_chat_id"
  ```

## Устранение неполадок

### Ошибка отправки сообщения
1. Проверьте правильность токена и Chat ID
2. Убедитесь, что бот добавлен в чат
3. Проверьте интернет-соединение

### Бот не отвечает
1. Отправьте команду `/start` боту
2. Проверьте права бота в группе (если используется групповой чат)

### Ошибки в логах
Проверьте файл лога Lynis для детальной информации о проблемах безопасности.

## Дополнительные возможности

- Интеграции с другими системами мониторинга
- Настройки различных уровней уведомлений
- Отправки файлов логов
