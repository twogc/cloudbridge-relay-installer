# 📚 Reference Repositories

Эта папка содержит скачанные репозитории, которые служат как шпаргалки и примеры для разработки P2P QUIC сервера.

## 📁 Содержимое

### **P2P QUIC примеры:**

#### **p2pquic/** - mengelbart/p2pquic
- **Описание**: Минимальный демо-проект QUIC + ICE/STUN
- **Ключевые файлы**: 
  - `ice.go` - базовая реализация ICE
  - `server.go` - QUIC сервер
- **Использование**: Пример P2P соединения через NAT

#### **quic-p2p/** - 0-u-0/quic-p2p  
- **Описание**: Библиотека с объектной моделью ICE
- **Ключевые файлы**:
  - `internal/mux/` - мультиплексирование
  - `examples/` - примеры использования
- **Использование**: Готовый ICE слой для QUIC

#### **openp2p/** - openp2p-cn/openp2p
- **Описание**: Готовая P2P сеть с поддержкой QUIC
- **Ключевые файлы**:
  - `lib/` - основные библиотеки
  - `example/` - примеры
- **Использование**: Референс для P2P архитектуры

### **QUIC серверы и прокси:**

#### **masque-go/** - quic-go/masque-go
- **Описание**: CONNECT-UDP/CONNECT-IP реализация
- **Ключевые файлы**:
  - `cmd/` - примеры серверов
  - `examples/` - демо приложения
- **Использование**: MASQUE для обхода корпоративных сетей

#### **quicssh/** - moul/quicssh
- **Описание**: SSH прокси поверх QUIC
- **Ключевые файлы**:
  - `cmd/` - клиент и сервер
  - `pkg/` - библиотеки
- **Использование**: Пример QUIC прокси сервера

#### **reverse-http/** - grepplabs/reverse-http
- **Описание**: Reverse proxy поверх QUIC/HTTP-3
- **Ключевые файлы**:
  - `cmd/` - сервер и клиент
  - `pkg/` - основные компоненты
- **Использование**: Пример длинноживущих QUIC соединений

## 🎯 Как использовать

### **Для изучения архитектуры:**
1. **p2pquic** - начать с простого примера
2. **quic-p2p** - изучить ICE интеграцию
3. **openp2p** - понять полную P2P архитектуру

### **Для реализации MASQUE:**
1. **masque-go** - готовая реализация CONNECT-UDP/CONNECT-IP
2. **reverse-http** - пример HTTP/3 сервера
3. **quicssh** - пример QUIC прокси

### **Для интеграции с нашим проектом:**
- Изучите структуру файлов в каждом репозитории
- Скопируйте нужные паттерны в наш код
- Адаптируйте под нашу архитектуру

## 📖 Документация

Каждый репозиторий содержит:
- `README.md` - описание и инструкции
- `go.mod` - зависимости
- `examples/` - примеры использования
- `cmd/` - исполняемые приложения
