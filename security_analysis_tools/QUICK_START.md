## 2. Использование в консоли

Откройте консоль браузера (F12) и выполните:

```javascript
// Быстрый анализ
const auditor = new ComprehensiveSecurityAudit();
auditor.init('https://example.com');
auditor.runFullAudit().then(console.log);

// Запуск примеров
SecurityExamples.runAllExamples();
```
