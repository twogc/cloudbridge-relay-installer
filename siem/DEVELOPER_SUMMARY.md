# 🎯 Краткое резюме для разработчика SIEM

## 📋 Что нужно сделать

### 1. **Адаптировать SIEM к существующей архитектуре**
- ✅ Удалены дублирующие конфигурации Prometheus/Grafana из папки `siem/`
- ✅ Создан скрипт интеграции `scripts/integrate_siem_monitoring.sh`
- ✅ Написано техническое задание `TECHNICAL_SPECIFICATION.md`

### 2. **Основные задачи разработчика**

#### 🔧 Backend API (FastAPI)
```python
# siem/backend/app/main.py
# Реализовать endpoints:
- /api/v1/events - сбор событий
- /api/v1/alerts - управление алертами  
- /api/v1/correlation - правила корреляции
- /api/v1/analytics - аналитика
- /api/v1/webhooks - интеграция с внешними системами
```

#### 📊 Интеграция с существующим мониторингом
```bash
# Запустить скрипт интеграции:
sudo ./scripts/integrate_siem_monitoring.sh --siem-ip <SIEM_SERVER_IP>
```

#### 🎨 Frontend (React)
```typescript
// siem/frontend/src/
// Компоненты:
- Dashboard - главная панель
- Events - просмотр событий
- Alerts - управление алертами
- Rules - настройка правил
- Analytics - аналитика
- Settings - настройки
```

### 3. **Ключевые требования**

#### 🏗️ Архитектура
- **Развертывание на отдельном сервере** (не в корне проекта)
- **Multi-tenant поддержка** с изоляцией данных
- **Интеграция с существующим Keycloak** для аутентификации
- **Использование существующих Prometheus/Grafana/AlertManager**

#### 🔒 Безопасность
- **TLS 1.3** для всех соединений
- **RBAC** per tenant
- **Audit logging** всех действий
- **Соответствие 152-ФЗ, 187-ФЗ**

#### 📈 Производительность
- **Events/sec**: > 10,000
- **Alert latency**: < 100ms
- **Uptime**: 99.9%
