# Cloudbridge Relay Admin Dashboard

Современная административная панель для управления Cloudbridge Relay сервером с интеграцией Keycloak для безопасной авторизации.

## 🚀 Возможности

### 🔐 Безопасная авторизация
- Интеграция с Keycloak OIDC
- Ролевая модель доступа (требуется роль `admin-ui`)
- Автоматическое обновление токенов
- Безопасный выход из системы

### 📊 Дашборд с информацией
- **Обзор системы**: статус API, информация о пользователе, состояние сервисов
- **Аудит логи**: просмотр событий безопасности и действий пользователей
- **Настройки**: управление конфигурацией (в разработке)

### 🎨 Современный интерфейс
- Адаптивный дизайн для всех устройств
- Красивые градиенты и анимации
- Интуитивно понятная навигация
- Темная тема с прозрачными элементами

## 🛠 Технологии

- **Frontend**: React 19 + TypeScript
- **Стили**: CSS3 с современными возможностями
- **Авторизация**: OIDC Client (oidc-client-ts)
- **Сборка**: Vite 4
- **Backend API**: Go + Gin + Keycloak

## 📋 Требования

- Node.js 18+ 
- Keycloak сервер с настроенным realm `cloudbridge`
- Пользователь с ролью `admin-ui`
- Admin API сервер на порту 8083

## 🔧 Конфигурация

### Keycloak настройки
Файл: `src/config/keycloak.ts`

```typescript
export const keycloakConfig = {
  authority: 'http://localhost:8080/realms/cloudbridge',
  client_id: 'relay-client',
  redirect_uri: window.location.origin + '/callback',
  // ... другие настройки
};
```

### API настройки
Файл: `src/api/adminApi.ts`

```typescript
const API_BASE_URL = 'http://localhost:8083';
```

## 📱 Использование

### 1. Авторизация
1. Откройте приложение в браузере
2. Нажмите "Войти через Keycloak"
3. Введите учетные данные в Keycloak
4. После успешной авторизации вы попадете в дашборд

### 2. Навигация
- **Обзор**: основная информация о системе
- **Аудит**: просмотр логов событий
- **Настройки**: управление конфигурацией

### 3. Функции
- **Обновление данных**: автоматическое обновление статуса
- **Фильтрация логов**: поиск по событиям
- **Экспорт**: сохранение данных (в разработке)

## 🔒 Безопасность

### Авторизация
- Все запросы к API требуют валидный JWT токен
- Токены автоматически обновляются
- Проверка роли `admin-ui` на каждом запросе

### CORS
- Разрешены только доверенные домены
- Заголовки авторизации защищены
- HTTPS в продакшн окружении

### Аудит
- Все действия пользователей логируются
- События безопасности отслеживаются
- Доступ к логам ограничен

## 📊 API Endpoints

### GET /api/status
Статус admin API сервера

**Ответ:**
```json

  "message": "Admin API is running"

```


## 🐛 Отладка

### Логи браузера
Откройте Developer Tools (F12) и проверьте:
- Console: ошибки JavaScript
- Network: запросы к API
- Application: токены и сессии

### Проверка авторизации
```javascript
// В консоли браузера
localStorage.getItem('oidc.user:http://localhost:8080/realms/cloudbridge:relay-client')
```

### Проверка API
```bash
# Без токена (должен вернуть 401)
curl http://localhost:8083/api/status

# С токеном (должен вернуть данные)
curl -H "Authorization: Bearer YOUR_TOKEN" http://localhost:8083/api/status
```

## 🔄 Обновления

### Добавление новых эндпоинтов
1. Добавьте эндпоинт в `internal/adminapi/server.go`
2. Добавьте функцию в `src/api/adminApi.ts`
3. Обновите типы в `src/api/adminApi.ts`
4. Используйте в компонентах

### Добавление новых страниц
1. Создайте компонент в `src/components/`
2. Добавьте стили в соответствующий CSS файл
3. Обновите навигацию в `Dashboard.tsx`

## 📝 Логирование

### Аудит события
Все события записываются в `logs/audit.log`:

```json
{
  "timestamp": "2024-01-15T12:15:00Z",
  "event": "dashboard_access",
  "user_id": "admin",
  "details": {
    "page": "overview",
    "session_id": "sess_12345"
  }
}
```

### Типы событий
- `user_login` - вход пользователя
- `user_logout` - выход пользователя
- `api_access` - доступ к API
- `dashboard_access` - доступ к дашборду
- `configuration_change` - изменение настроек
- `security_alert` - события безопасности
- `backup_created` - создание резервных копий
